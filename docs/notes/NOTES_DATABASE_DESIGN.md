# 1. PostgreSQL Schema

Notes Service chịu trách nhiệm quản lý toàn bộ dữ liệu ghi chú, tài liệu, cây thư mục và lịch sử chỉnh sửa.

Mỗi Page thuộc một Workspace.

Workspace
└── Pages
└── Blocks

---

## A. Pages

### Table: pages

| Column         | Type         | Constraint               | Description     |
| -------------- | ------------ | ------------------------ | --------------- |
| id             | UUID         | PK                       | Page ID         |
| workspace_id   | UUID         | FK → workspaces(id)      | Workspace       |
| parent_id      | UUID         | FK → pages(id), NULLABLE | Page cha        |
| title          | VARCHAR(500) | NOT NULL                 | Tiêu đề         |
| icon           | TEXT         | NULLABLE                 | Emoji/Icon      |
| cover_url      | TEXT         | NULLABLE                 | Cover image     |
| order_index    | INTEGER      | DEFAULT 0                | Thứ tự hiển thị |
| created_by     | UUID         | FK → users(id)           | Người tạo       |
| last_edited_by | UUID         | FK → users(id)           | Người sửa cuối  |
| is_archived    | BOOLEAN      | DEFAULT FALSE            | Đã archive      |
| is_deleted     | BOOLEAN      | DEFAULT FALSE            | Trong trash     |
| deleted_at     | TIMESTAMPTZ  | NULLABLE                 | Thời điểm xóa   |
| created_at     | TIMESTAMPTZ  | DEFAULT NOW()            | Tạo lúc         |
| updated_at     | TIMESTAMPTZ  | DEFAULT NOW()            | Cập nhật lúc    |

Indexes

- workspace_id
- parent_id
- is_deleted
- is_archived

## B. Blocks

### Table: blocks

| Column      | Type        |
| ----------- | ----------- |
| id          | UUID        |
| page_id     | UUID        |
| type        | VARCHAR(50) |
| content     | JSONB       |
| order_index | INTEGER     |
| created_at  | TIMESTAMPTZ |
| updated_at  | TIMESTAMPTZ |

Supported Block Types

- paragraph
- heading_1
- heading_2
- heading_3
- bullet_list
- numbered_list
- todo
- quote
- code
- image
- file
- callout
- divider

Example content

{

}

Code Block

{
"language": "typescript",
"code": "console.log('hello')"
}

# 2. Redis Strategy

| Purpose      | Key                     | TTL |
| ------------ | ----------------------- | --- |
| Page Cache   | note:page:{id}          | 30m |
| Tree Cache   | note:tree:{workspaceId} | 15m |
| Search Cache | note:search:{hash}      | 10m |
| Presence     | note:presence:{pageId}  | 30s |

---

# 3. Create Page Flow

1. Validate workspace.
2. Validate parent page.
3. Create page.
4. Update sidebar tree cache.
5. Return page.

---

# 4. Update Page Flow

1. Load page.
2. Update metadata.
3. Update updated_at.
4. Invalidate cache.

---

# 5. Page Tree Management

Parent-child structure.

Workspace
├── Backend
│ ├── NestJS
│ └── CQRS
└── AI
├── RAG
└── LangGraph

Tree generated by parent_id.

# 6. Block Editor Flow

1. Create block.
2. Update block.
3. Delete block.
4. Reorder block.

All content stored in blocks table.
